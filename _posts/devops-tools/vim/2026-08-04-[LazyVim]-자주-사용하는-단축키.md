LazyVim에서 자주 사용하며 기본적인 단축키에 대해 알아본다.  
LazyVim은 단축키가 매우 직관적이며 Space(리더키)를 누르면 하단에 힌트 창이 뜨니 참고

---

## 파일 탐색 및 네비게이션
- \<leader\> e : 좌측 파일 탐색기(Neo-tree) 토글 (켜고 끄기)
- \<leader\> f f : 전체 프로젝트에서 파일명으로 파일 찾기 (Fuzzy Finder)
- \<leader\> s g : 파일 내부의 특정 텍스트(단어) 검색 (Live Grep)
- \<leader\> f r : 최근에 열었던 파일 목록 보기 (Recent Files)

## 탭(버퍼) 관리
- Shift + h / Shift + l : 상단 탭 왼쪽 / 오른쪽으로 이동
- \<leader\> b d : 현재 활성화된 탭(버퍼) 닫기

## 창(윈도우) 관리
- \<leader\> w v : 창 세로 분할
- \<leader\> w s : 창 가로 분할
- Ctrl + h / j / k / l : 분할된 창 사이로 커서 이동
- \<leader\> w d : 현재 분할 창 끄기

## 코드 편집 및 이동
- g d : 함수나 변수가 정의된 곳으로 원래 소스로 이동 (Go to Definition)

## 터미널
- \<leader\> f t 또는 Ctrl + / : 하단에 가상 토글 터미널 켜고 끄기
